# 内容管理后台手册

## 日常操作 `/admin/`

1. 使用已在 Cloudflare 中配置的管理员密码登录；生产登录还需要 Turnstile。会话8小时后到期，使用 HttpOnly、SameSite Cookie。
2. 在“页面内容”中选择栏目和语言。修改标题、简介、补充正文。正文按纯文本显示，避免插入脚本。
3. 点击“保存并发布”。前台重新打开或刷新后从 D1 读取内容，不需要手动上传数据库。
4. 在媒体库上传 PNG/JPG/WebP/GIF、MP3/OGG/WAV、MP4/WebM 或 PDF。单文件最高20MB；SVG/HTML和伪装文件被拒绝。
5. 点击“插入当前页面”，会填入媒体链接、类型、说明；再保存发布。图片显示在内容区，音视频有播放器，PDF显示下载/查看入口。请填写有意义的描述。
6. 可删除不再被已发布 D1 内容引用的文件。删除前有二次确认；引用中的文件会拒绝删除。Git 默认内容引用的文件需人工确认。
7. 下方查看近期100条咨询、业务分类与 CRM/邮件状态。“重试待同步”一次最多处理10条。未配置外部服务时保持 pending，不会伪报已送达。
8. 使用“退出登录”结束浏览器会话；共享设备上请关闭浏览器。怀疑会话泄露时轮换 ADMIN_SESSION_SECRET。

联系人包含个人信息，只有授权运营人员可以访问。不要将后台截图公开。

## Git 内容编辑 `/admin/git/`

Sveltia 使用 GitHub OAuth；配置方法见部署文档。它编辑 `shared/pages.json` 并提交 Git，适合维护默认文案和SEO构建。21条记录对应7栏目×3语言，不要创建重复 slug/language 记录。

D1 已发布的同页内容覆盖 Git 默认文案。为避免混乱，日常内容以数据库后台为主，SEO更新由负责人同步到Git。不会自动双向同步。

当前首页服务卡片、导航和基础多语言界面文案在 `shared/content.js`；数据库后台可编辑各页标题、简介、补充正文、一个主媒体块。复杂新增版块、自由排版和独立博客文章编辑器不在当前后台字段中，需另行扩展，不能把当前后台当作无限制页面构建器。
